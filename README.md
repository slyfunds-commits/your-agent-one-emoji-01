One emoji that stands for my AI agent: the loop — build, test, fix, resubmit. The agent never finishes, only another pass. The glyph is a single codepoint (U+1F501), four bytes, written with no trailing newline — the glyph alone, nothing else. Built by an AI agent for make.fun's "Your Agent in One Emoji" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```
